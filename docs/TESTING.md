## Reproduce

Install exact JS dependencies with `bun install --frozen-lockfile --ignore-scripts`. Run `bash scripts/fetch-raydium.sh` to download the devnet program read-only and verify the reviewed hash. An existing or newly downloaded different hash fails closed; inspect a changed deployment before accepting it.

Run `FLINCH_EVIDENCE_DIR=artifacts/runs/<unique-run> bash scripts/verify-v2.sh`. This builds the V2 SBF/IDL before running in-process tests. `bash scripts/verify-domain.sh` remains the fast domain-only entrypoint.

The successful stack used Node 24.14.1, Agave test-validator 3.1.10 and the pinned MagicBlock 0.14.10 package. Put the already-installed 3.1.10 binary directory on PATH for this command only; then run `bun run test:stack`, `bun run test:stack:expiry`, `bun run test:stack:keeper` and `bun run test:stack:keeper:expiry` separately. Do not run stacks concurrently. No public faucet or deployment command is involved: programs/accounts are loaded into isolated local genesis, and its mint funds in-memory test wallets.

Reserved localhost ports: base 18899/18900, ER 17799/17800, query service 16699/16700, faucet 19900, dynamic validator range 20000–20100. The harness checks fixed TCP ports before startup, records run directories, and terminates its supervisor in finally. Check for leftover child processes if shutdown reports failure; never kill unrelated validators by name.

Quote-backed commands: `bun run test:stack:quotes` and `bun run test:stack:quotes:expiry`. Browser: `bun run test:browser:stack`, additionally reserving localhost 3300. Supply `FLINCH_BROWSER_EXECUTABLE` for an existing Chromium executable if the installed Playwright browser is unavailable. Verified here with cached Chromium revision 1223 and Playwright 1.63.0. No browser or validator global installation was changed.

UI-only: `bun run --cwd apps/web build`, then `bun run --cwd apps/web start` in a separate terminal, followed by `bun run test:browser:ui`. It defaults to `http://127.0.0.1:3000`; `FLINCH_UI_URL` may select another loopback port. It does not submit transactions. Supply the same existing Chromium executable when needed. Keep this separate from the local transaction stack, which runs a development server with synthetic local configuration.

### Toolchain caveats

- Host Rust/Cargo 1.94.1 is selected by the existing RUSTUP_TOOLCHAIN override. The declared host 1.89.0 remains unverified.
- SBF uses platform-tools v1.53. Build-side Solana CLI 2.3.0 warns that standard syscalls are unknown; the resulting artifact executes successfully in LiteSVM and the real local stack. The checker still rejects stack-overflow/error output. Reconcile the build tooling before release; do not suppress this warning as proof of compatibility.
- Anchor runtime and macro crates are locked to 1.0.2. Both program crates allow one Anchor-generated Clippy lint; this is the only change to the legacy implementation. Token-2022 is an IDL-only Anchor SPL compatibility feature, not a production token route.
- Early-genesis V0 transfers were accepted in preflight but dropped during sanitization on Agave 2.3.0/3.1.10. The precise cause is not proven. Stack messages are legacy and size-checked; this is not a claim that V0 is generally unsupported.
- The original SDK commitment helper delayed second-cycle observation until expiry. The adapter now polls the same upstream log format without its blocking confirmation call. Base confirmation and ownership checks remain mandatory. Earlier failed runs and signatures remain retained; no game deadline was relaxed.
